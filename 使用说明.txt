===================================
  Guardian 使用说明
===================================

【前提条件】
  已安装 Python 3.10 或更高版本
  下载地址：https://www.python.org/downloads/
  安装时务必勾选 "Add Python to PATH"

===================================
  第一步：安装依赖
===================================

  双击 install.bat，等待安装完成

  如果安装失败（网络问题），可以手动执行：
  pip install -r requirements.txt

===================================
  第二步：启动程序
===================================

  双击 run.bat 启动 Guardian

  启动后会在系统托盘（右下角）显示图标

===================================
  第三步：配置
===================================

  1. 选择要隐藏的窗口
     - 点击「🔄 刷新」扫描当前窗口
     - 点击勾选要隐藏的窗口
     - 点击「💾 保存选择」

  2. 设置排除区域（可选）
     - 在摄像头画面上按住鼠标拖拽，画出红色虚线框
     - 框内的人不会触发隐藏
     - 可以画多个区域
     - 点击「清除区域」可全部清除

  3. 调整参数（可选）
     - 触发阈值：检测到几人时触发隐藏（默认2人）
     - 恢复延迟：人离开后等几秒恢复（默认3秒）

===================================
  运行逻辑
===================================

  摄像头持续检测画面中的人数
  ↓
  人数 ≥ 阈值 → 自动最小化目标窗口
  ↓
  人数 < 阈值 → 等待恢复延迟 → 自动恢复窗口

===================================
  操作按钮
===================================

  ⏸ 暂停    - 暂停监控，不检测不隐藏
  🔄 刷新    - 重新扫描当前窗口列表
  💾 保存选择 - 保存勾选的窗口
  清除区域   - 清除所有排除区域

===================================
  关闭程序
===================================

  点击窗口右上角 X → 最小化到托盘（不退出）
  托盘图标右键 → 退出

===================================
  常见问题
===================================

  Q: 摄像头打不开？
  A: 检查是否有其他程序占用摄像头，关闭后重试

  Q: 检测不到人？
  A: 确保光线充足，人正面朝向摄像头

  Q: 依赖安装失败？
  A: 检查网络，或使用镜像源：
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
