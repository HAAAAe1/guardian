# Guardian 🛡️

摄像头人物检测 + 窗口自动隐藏工具。

检测到多人时自动最小化指定窗口，人离开后自动恢复显示。

## 功能

- 📷 摄像头实时画面 + 人框标注
- 👥 检测到指定人数自动最小化窗口
- 🔄 人离开后自动恢复显示（可设延迟）
- ☑️ 运行时动态选择要隐藏的窗口
- 🚫 框选多个排除区域（区域内的人不计入检测）
- ⏸ 一键暂停/恢复监控
- 🖥 系统托盘运行，关闭窗口不退出

## 安装

```bash
pip install -r requirements.txt
```

依赖：ultralytics, opencv-python, pywin32, pystray, Pillow

## 使用

```bash
python guardian_gui.py
```

1. 打开界面，点击 **🔄 刷新** 扫描当前窗口
2. 勾选要隐藏的窗口，点 **💾 保存选择**
3. 在摄像头画面上**拖拽**画出排除区域（如身后位置）
4. 程序自动监控，检测到多人时最小化目标窗口

## 配置

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 触发阈值 | 2人 | 检测到几人时触发 |
| 恢复延迟 | 3秒 | 人离开后等待多久恢复 |
| 摄像头 | 0 | 摄像头编号 |
| 检测间隔 | 0.5秒 | 每次检测间隔 |
| 置信度 | 0.5 | YOLO 检测阈值 |

## 排除区域

在摄像头画面上用鼠标拖拽画框，框内的人不计入检测。支持多个区域，适合身后有人但不想触发隐藏的场景。
