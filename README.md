# Guardian 🛡️

摄像头人物检测 + 窗口自动隐藏工具。

检测到多人时自动最小化指定窗口，人离开后自动恢复显示。

## 功能

- 📷 摄像头实时画面 + 人框标注
- 👥 检测到指定人数自动最小化窗口
- 🔄 人离开后自动恢复显示
- ☑️ 运行时动态选择要隐藏的窗口
- ⏸ 一键暂停/恢复监控
- 🖥 系统托盘运行，关闭窗口不退出

## 安装

```bash
pip install ultralytics opencv-python pywin32 pystray Pillow
```

## 使用

```bash
python guardian_gui.py
```

1. 打开界面，点击 **🔄 刷新** 扫描当前窗口
2. 勾选要隐藏的窗口
3. 点 **💾 保存选择**
4. 程序自动监控，检测到多人时最小化目标窗口

## 配置

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 触发阈值 | 2人 | 检测到几人时触发 |
| 摄像头 | 0 | 摄像头编号 |
| 检测间隔 | 0.5s | 每次检测间隔 |
| 置信度 | 0.5 | YOLO 检测阈值 |
